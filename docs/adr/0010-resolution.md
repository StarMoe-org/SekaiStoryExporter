# ADR-0010: 分辨率：严格原生

- **状态**：accepted
- **日期**：2026-09-24

## 背景

游戏在剧情中不改变分辨率，后备缓冲就是设备的原生分辨率；UI、背景和文字按原生分辨率光栅化。角色则先渲染进固定大小的 RenderTexture，再缩放合成，所以高分辨率下角色会略微变软。

## 决策

- 输出分辨率就是游戏的「原生屏幕」：UI、背景和文字按目标分辨率光栅化；角色固定渲染进 2304×1536 的 RT，再按 `ContentSize.y / 1024` 缩放合成。
- 不提供角色超采样或其他非还原的分辨率开关。
- 支持任意分辨率和宽高比。需要与某台设备的录像对照时，按该设备的原生分辨率渲染，再用 `--output-size` 缩放编码。

## 后果

- 正面：任意分辨率下都与对应设备上的游戏一致，包括模糊半径等依赖分辨率的效果。
- 负面：在高分辨率下角色不会比游戏更清晰。

## 复审条件

游戏改变角色 RT 的尺寸或合成方式时。
