# ADR-0012: 版本策略

- **状态**：accepted
- **日期**：2026-09-22

## 背景

游戏会持续更新，剧情播放器的行为和常量可能随之变化。本项目是长期项目，正确性优先于速度。

## 决策

- 每个 sse 版本锁定所支持的游戏版本（按区服），更新后**手动适配**。当前支持 CN 6.4.0 与 JP 6.8.1。
- 与游戏行为相关的常量集中在 `sse_core::consts`，每项注明对应的游戏类或方法。
- 适配步骤见 [`versioning.md`](../versioning.md)。

## 后果

- 正面：每个版本的行为都可复现、可追溯。
- 负面：游戏更新后需要人工核对。

## 复审条件

游戏更新频繁到手动适配跟不上时。
