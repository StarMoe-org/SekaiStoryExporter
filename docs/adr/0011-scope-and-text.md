# ADR-0011: 内容范围与文字渲染

- **状态**：accepted
- **日期**：2026-09-25

## 背景

游戏里的剧情有 Live2D 对话、3D MV、全屏影片等多种形式。文字由 TextMeshPro 渲染：动态 SDF 图集，源字体随客户端分发。CN 客户端把思源黑体 SC 改名为 FOT-RodinNTLG Pro 放入客户端，日服客户端则是真正的 FOT-RodinNTLG Pro；两边的对话框排版参数（FaceInfo、字号、行距）相同。

## 决策

- 范围：Live2D 2D 对话剧情。其余内容（如 MV）按 ADR-0008 的 `Unsupported` 处理。
- 文字：用客户端自带的源字体直接光栅化（CPU、纯 Rust，各平台结果一致），字号、行距、自动缩放和描边层按游戏参数复刻。UI 套件里没有客户端字体时，CN 退回思源黑体 SC。
- 与 TMP SDF 的差异（边缘略有不同、富文本标签不解释）写入导出报告。

## 后果

- 正面：两个区服用同一套排版代码，只换字体文件。
- 负面：边缘抗锯齿与 SDF 略有差异。

## 复审条件

需要逐像素对齐文字边缘时，改为实现 SDF 路径。
