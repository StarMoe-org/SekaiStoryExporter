# ADR-0001: 用 ADR 记录架构决策

- **状态**：accepted（取代早期的「决策总表 + ADR」双层结构）
- **日期**：2026-09-25

## 背景

项目早期用一份决策总表（Q1–Q42）集中记录决策，重大变更再补 ADR。总表里混着评审过程、里程碑和临时约定，公开后读者难以分辨哪些仍然有效。

## 决策

只保留 ADR。原总表中仍然有效的决策按主题合并为 ADR-0002 至 ADR-0014；已被取代或只属于过程的条目不再保留。

## 后果

- 正面：每项决策可以单独链接、单独修订；只有一处事实来源。
- 负面：跨主题的背景需要在各篇里分别交代。

## 复审条件

ADR 数量多到难以浏览时，按主题分目录。
