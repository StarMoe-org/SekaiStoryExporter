# ADR-0008: 中间表示（IR）

- **状态**：accepted
- **日期**：2026-09-24

## 背景

剧本数据（ScenarioSceneData）是游戏的序列化格式，字段含义依赖上下文，不适合直接驱动时间轴。细节见 [`spec/ir.md`](../spec/ir.md)。

## 决策

- **薄 IR**：规范化的、带类型的指令序列，保留原始下标、推进方式、延迟和完成规则；**不含绝对时间**，时序完全由 `sse-timeline` 模拟得到。
- **不支持的内容**表示为 `Unsupported{reason, finish, raw}`，照常参与调度，完成语义与游戏一致，画面上留空，并写入导出报告。
- **分支**：保留分支树；导出默认走第一项，可用 `--branch` / `--all-branches` 选择。只有 Action = 5 产生分支。
- **持久化**：Rust 类型加带 `ir_version` 的调试 JSON（`sse inspect`），不承诺稳定的外部格式。
- **1:1 复刻**：不做人工覆盖，游戏自身的数据错误照样保留。
- `{{playerName}}` 用配置 `player_name` 替换，默认 `「世界」的居民`，可用 `--player-name` 覆盖。

## 后果

- 正面：IR 简单，时间相关的行为只在一处实现。
- 负面：IR 本身不能直接回答「某条指令在第几帧」，要跑时间轴。

## 复审条件

需要对外提供稳定的剧本格式时。
