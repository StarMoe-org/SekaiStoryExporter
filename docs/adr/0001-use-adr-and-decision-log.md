# ADR-0001: 决策记录的双层结构

- **状态**：accepted
- **日期**：2026-09-22

## 背景

项目在开工前通过一轮结构化评审确定了 18 项架构决策（Q1–Q18）。这些决策彼此耦合，且部分带有已知风险（如 Q8）。长期维护中需要能回答「当初为什么这么选」。

## 决策

采用双层结构：

- `docs/decisions.md` — **总表与索引**。所有决策的结论、关键后果、注记。日常查阅入口。
- `docs/adr/NNNN-*.md` — **单条详述**。仅在以下情况创建：
  - 变更一项已有决策
  - 新增一项影响多个 crate 的决策
  - 决策过程中有值得保留的备选方案分析

Q1–Q18 不回溯补写 ADR——它们的上下文已在 `decisions.md` 与 `risks.md` 中记录充分。

## 后果

- 正面：日常只需维护一个总表；重大变更才付 ADR 的成本
- 负面：两处需保持同步（PR 清单已包含该检查项）

## 复审条件

若 ADR 数量超过 20 且总表开始滞后，改为以 ADR 为准、总表自动生成。
