# ADR-0009: 时间轴：按帧模拟，60 fps

- **状态**：accepted
- **日期**：2026-09-24

## 背景

游戏的剧情播放由 Unity 协程驱动：`yield null`、`WaitForSeconds`、`elapsed += deltaTime`（f32）。如果把秒数一次性换算成帧，会与游戏的逐帧量化结果不一致。

## 决策

- `sse-timeline` 以固定步长逐帧模拟协程调度，用 `elapsed < duration` 决定是否再等一帧，量化结果自然与游戏一致。
- 模拟帧率为 60：剧情沿用 UI 的目标帧率，每个逻辑帧渲染一帧。导出 60 fps 时，一个模拟帧对应一个视频帧。
- 刷新率不是 60 的倍数时的其他帧率分支不建模。

## 后果

- 正面：对话节奏、淡入淡出的起止帧与游戏逐帧对应。
- 负面：只支持 60 fps 导出。

## 复审条件

游戏改变剧情帧率，或需要其他帧率的导出时。
