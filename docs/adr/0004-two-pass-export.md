# ADR-0004: 两阶段导出与无状态渲染

- **状态**：accepted
- **日期**：2026-09-22

## 背景

Live2D 的动作淡入淡出与物理是累积状态，不能任意跳帧；但状态更新（纯 CPU、很快）与渲染（GPU、较慢）可以分离。

## 决策

- 内核是无状态的 `render(frame_n)`，预览器与导出器只是两个不同的驱动循环。
- 导出分两阶段：Pass 1（`sse-bake`）顺序推进时间轴，只更新状态，产出逐帧的参数表；Pass 2（`sse-render`）只读参数表，每帧独立渲染，可并行。
- `sse-render` 不得依赖 `sse-timeline` 或 `sse-scenario`，这是 Pass 2 无状态性的结构保证。
- 调试输出（分层、draw call dump 等）全部做成开关，默认关闭。

## 后果

- 正面：参数表把「曲线求值错了」和「渲染错了」分开，可以逐数值比对；渲染可并行，预览可以瞬间跳转。
- 负面：多一层中间格式需要维护（`sse-params`，带版本号）。

## 复审条件

参数表的体积或生成时间成为瓶颈时。
